What is Lazy Loading?

Lazy loading is a design pattern that defers the loading of modules until they are actually needed. This helps reduce the initial bundle size and improves application startup time.

Benefits of Lazy Loading:

  • Smaller Initial Bundle: Only core modules are loaded at startup
  • Faster Load Time: Users see the app faster
  • On-Demand Loading: Features load only when needed
  • Better Performance: Reduced memory footprint
  • Improved UX: Faster time to interactive

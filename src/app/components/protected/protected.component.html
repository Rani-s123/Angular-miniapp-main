Welcome to the Protected Area!

You successfully accessed this protected route because you are authenticated. This route is guarded by the AuthGuard which implements the CanActivateFn interface.

How Route Guards Work:

  • The AuthGuard checks authentication status before allowing access
  • If not authenticated, users are redirected to the home page
  • Guards can inject services using the inject() function
  • Guards return true to allow access or false to deny

Route Configuration:

{{'{'}}
  path: 'protected',
  component: ProtectedComponent,
  canActivate: [AuthGuard]
{{'}'}}

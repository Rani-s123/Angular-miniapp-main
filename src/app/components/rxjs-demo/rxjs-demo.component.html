Key Differences

Subject vs BehaviorSubject

  • Subject: No initial value, new subscribers miss past emissions
  • BehaviorSubject: Has initial value, new subscribers get current value immediately
  • BehaviorSubject: Always has a current value accessible via .value

SwitchMap vs MergeMap

  • SwitchMap: Cancels previous inner observable when new value arrives
  • MergeMap: Keeps all inner observables running concurrently
  • Use switchMap: For search queries, user actions
  • Use mergeMap: When you need all results (file uploads, etc.)
